# Editor Automático — servidor V7
Servidor Node/Express + FFmpeg nativo para o editor web.

## Campos multipart
- videos: até 5 vídeos
- watermark: imagem opcional
- template: news-card, clean ou headline
- headline: título
- caption: legenda
- handle: @usuário
- logoSize: 40–260
- mirror: true/false
- speed: 0.5–2

Saída: 720x1280 (9:16), H.264 + AAC.
